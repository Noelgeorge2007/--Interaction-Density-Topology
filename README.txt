PI-IDT: REFERENCE IMPLEMENTATION AND SUPPORTING DATA

The reference implementation of the pi-IDT pipeline, including density-matrix
partitioning, accessibility masking, cubical persistent homology and descriptor
extraction, together with supporting data and scripts for regenerating the
reported analyses, tables and figures, is provided in this repository:
https://github.com/Noelgeorge2007/--Interaction-Density-Topology

This README provides installation instructions, execution order and guidance
distinguishing analysis of stored results from rerunning electronic-structure
calculations. Dependencies include RDKit, tblite, ASE, PySCF, GUDHI, NumPy,
SciPy, pandas, scikit-learn and Matplotlib. Manuscript text is not included.

INSTALLATION AND QUICK CHECK

Use Python 3.13 in an isolated environment. From the repository root:

    python3 -m venv .venv
    source .venv/bin/activate
    python -m pip install -r requirements-analysis-tested.txt
    python scripts/verify_data.py
    python scripts/check_regression.py
    bash run_all.sh cached

Windows users can run the shell workflow under a compatible Linux environment.
The tested analysis versions are pinned in requirements-analysis-tested.txt.
requirements-analysis.txt lists the direct dependencies without version pins.
No LaTeX installation or manuscript folder is needed for this workflow.

REPRODUCTION MODES

cached: regenerates summaries, five tables, numerical macros and figures using
supplied calculation results and fitted-regression outputs. It does not rerun
DFT or refit regression models. Figure 1 uses figures/data/benzene_field.npz.

analysis: bash run_all.sh analysis also refits regression models and performs
the original permutation tests. These tests may take substantial time.

all: install requirements-compute.txt, then run bash run_all.sh all for the
calculation pipeline followed by analysis. Some original calculation scripts
reuse existing records. To calculate into separate empty output directories:

    export PIDT_RESULTS="$PWD/fresh-run/results"
    export PIDT_FIGURES="$PWD/fresh-run/figures"
    export PIDT_ANALYSIS="$PWD/fresh-run/analysis_outputs"
    mkdir -p "$PIDT_RESULTS" "$PIDT_FIGURES/data"
    bash run_all.sh all

Without the benzene-field cache, Figure 1 is recalculated too. Inspect logs for
FAIL, traceback and convergence errors: original Python scripts can catch a
molecule failure and continue. Verify completeness before comparing fresh
results against archived data. Do not mix different parameter settings in one
result directory. Full-computation dependencies have not been tested during
this repository preparation. Timings depend on hardware and environment.

FILES AND RESULTS

src/molecules.py: molecular definitions as SMILES and group labels.
src/pidt.py: density partition, accessibility mask, persistence and descriptors.
src/opt.py: geometry preparation; src/probes.py: interaction-energy protocol.
src/run_*.py: descriptor, probe-energy and sensitivity calculations.
src/regress2.py: reported repeated five-fold cross-validation, 50 repeats.
src/regress.py: earlier leave-one-out analysis discussed in the study.
src/analysis*.py, make_aux.py, panels.py, export_figs.py: summaries and figures.

results/setA.json: 39 molecular records with coordinates, density diagnostics,
descriptors and persistence diagrams. Coordinates are in angstrom, persistence
thresholds in atomic units and accessible-density integrals in electrons.
results/setB.json: 26 molecules with four probe-energy targets in kcal/mol.
results/esp_axial.json: axial electrostatic potentials used by the baseline.
results/regression.json: reported repeated-cross-validation outputs.
results/regression_loo.json: superseded leave-one-out results, retained because
the manuscript discusses them; not independent validation data.
results/robust.json, rotation_v2.json, poav_v2.json: robustness/partition tests.
results/mask_series.json, shield_poav.json: mask sensitivity and shielding.
Other JSON and CSV files hold supporting sensitivity tests and derived tables.

Figure 1: figures/data/benzene_field.npz, regenerated by panels.py if absent.
Figure 2 and descriptor table: setA.json, nring.json, shield_poav.json.
Figure 3 and robustness table: robust.json and rotation_v2.json.
Figure 4 and regression table: setB.json, esp_axial.json, regression.json.
Correlation table: setB_table.csv and univariate.csv.
Mask table: mask_series.json.
The four reference composite figures are included in figures/composite/.

Generated table fragments and numerical macros go to analysis_outputs/;
these are analysis products, not manuscript source. The directory is ignored
by Git. Figures and auxiliary plots are generated under figures/.

Full wavefunctions and volumetric fields for every molecule are not included;
calculation code is supplied to regenerate them. Archived coordinates and bars
are rounded, so they do not retain every unrounded intermediate value.

PARAMETERS AND REPRODUCIBILITY

Default descriptor calculation: GFN2-xTB geometry preparation, wb97x-d3bj/6-31G*
electronic structure, grid spacing 0.15 angstrom, padding 3.5 angstrom.
Accessibility defaults: radius scale 1.0, smoothing width 1.0 angstrom;
pi-atom population threshold 0.15 electrons; persistence cutoff 0.005 a.u.
See run_setA.py, pidt.py and probes.py for complete calculation settings.
RDKit embedding defaults to seed 0xf00d; geometry restarts use NumPy seed 0.
Cross-platform geometry and floating-point differences remain possible.

VERIFICATION AND LIMITS

During package preparation, all 39 descriptor records and all 26 x 4 energy
targets passed integrity checks. All 24 repeated-cross-validation models were
refitted from archived inputs: maximum difference in mean Q2 was 8.89e-15.
Permutation tests and bootstrap confidence limits were not recomputed.
The original cached workflow regenerated all five tables and numerical macros
exactly. The manuscript-free workflow was also tested after adapting output
paths. The underlying scientific calculation code and primary data are retained.

The full geometry, DFT, interaction-energy and robustness calculations were not
rerun. No independent theoretical validation or literature audit is claimed.
The archived benchmark does not show a predictive gain from adding pi-IDT.
Small sample size, fixed probe geometries, empirical mask settings, grid effects
and the approximate curved-system partition limit generalization.

MANIFEST.sha256 records primary-data and Figure 1 cache checksums. verify_data.py
checks these plus data completeness and headline summaries. check_regression.py
refits the 24 models using the supplied estimator functions without rerunning
the permutation/bootstrap calculations. It is a reproduction check, not an
independently implemented estimator.
